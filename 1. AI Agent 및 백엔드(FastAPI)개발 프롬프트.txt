1. AI Agent 및 백엔드(FastAPI)개발 프롬프트
FastAPI와 SQLite를 기반으로(추후 Firebase로 다른 프로젝트에 넣어야함), 척추(L1~L4) 추출 및 골밀도(BMD) 측정을 수행하는 독립적인 'BMD AI Agent' 아키텍처와 서버 코드를 작성해줘. 

현재 프로젝트는 프론트엔드/백엔드로 구성할것이고, 나중에 다른 프로젝트(시스템)의 일부 메뉴로 결합하려고 해.

[프로젝트 환경 및 기술 스택]
- Framework: FastAPI (Python)
- Database/Storage: SQLite
- Model Path: `./Models/best.pt`
- 아키텍처 방향: 단순 API가 아닌, 사용자의 요청을 해석하고, 전처리 -> 추론 -> 메타데이터 파싱 -> SQLite 저장 및 결과 리턴까지의 워크플로우를 자율적으로 수행하는 'BMD 전용 AI Agent' 패턴으로 구현.
- 필요하다면 vector data를 저장하는 vector db도 구축해줘

[BMD AI Agent 요구사항 및 흐름]
1. Storage 연동: 클라이언트가 업로드한 X-ray 원본 이미지를 SQLite 에서 가져오거나, 저장공간을 만들어 저장& 로드 한다.
2. 척추 추출 및 BMD 추론: `best.pt` 모델을 구동하여 L1~L4 척추 부위를 세그멘테이션하고, 골밀도 상태 수치(T-score 등)를 계산합니다.
3. 설명 가능한 AI(XAI): 모델이 어느 부위를 보고 골밀도를 측정했는지 나타내는 Grad-CAM 등의 분석 이미지를 생성합니다.
4. SQLite 저장: 분석이 끝나면 해당 고객 ID 하위에 아래 데이터를 구조화하여 자동 저장 해야 합니다.
   - 메타정보 (파일명, 촬영일시 등)
   - BMD 분석 수치 및 골다공증 위험도 결과
   - Storage에 업로드된 결과 이미지 URL (원본이미지, 척추 5개 추출본 및 XAI 결과 이미지)

추후 합쳐질 프로젝트의 소스코드와 독립적으로 동작하면서도 DB와 깔끔하게 연동되는 `bmd_agent.py` 스크립트와 이를 호출하는 FastAPI 라우터 코드를 작성해줘. (SQLite 초기화 및 생성스크립트 포함)


2. 프론트엔드(React/JSX) BMD 파트 연동을 위한 프롬프트
React(Vite)와 SQLite(추후 Firebase로 변경 예정)를 사용하는 프로젝트에서, 'BMD(골밀도) 파일업로드, 분석 결과 화면 및 팝업창' 컴포넌트를 구현해줘. 다른 사람들이 만든 기존 화면 구조(Frontend/src/pages/)에 자연스럽게 붙일 수 있는 독립적인 코드여야 해.

[화면 UI/UX 및 데이터 연동 요구사항]
1. 메인 화면 - BMD 결과 연동:
   - 좌측 상단 [고객 간단 정보] 아래쪽이나 우측 영역에 위치할 BMD 전용 컴포넌트야.
   - X-ray 사진 업로드 버튼이 있으며, 업로드 시 서버저장 및 BMD AI Agent API와 연동되어 분석을 시작해.
   - [X-ray 이력 목록]에서 특정 이력을 클릭하면, Firestore에서 해당 시점의 BMD 데이터(골다공증 여부 수치)를 읽어와 메인 대시보드 게이지에 동적으로 반영해줘.

2. 상세보기 팝업창 (BMD Detail Modal):
   - 이력 항목의 '상세보기' 클릭 시 열리는 팝업창이야.
   - Firestore에서 가져온 [X-ray 메타정보]를 렌더링해줘.
   - 척추뼈 5개가 추출된 분석 완료 이미지와 AI가 주목한 위치를 보여주는 XAI 이미지를 Firebase Storage URL로부터 받아와 좌우 대조 형태로 배치해줘.
   - 부위별(L1~L4) 골밀도 상태 수치를 깔끔한 테이블(Table)이나 리스트 형태로 시각화해줘.

[기술 요구사항]
- Firebase v9+ JS SDK (Firestore, Storage)를 사용하는 React 함수형 컴포넌트로 작성해줘.
- 타 파트 컴포넌트에 import하여 바로 쓸 수 있도록 `BmdDashboard.jsx`와 `BmdDetailModal.jsx` 형태로 모듈화된 코드를 제공해줘.
